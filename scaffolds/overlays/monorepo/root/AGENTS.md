## 📦 Shared Packages: the No-Drift Contract

`packages/*` holds the code that must be identical on both sides of the wire. Each package is a private workspace `@{{PROJECT_NAME}}/<name>`; read its `README.md` for what goes in and what does not.

- `shared-types`: cross-wire TypeScript types (built to `dist`, mirrored into both apps).
- `shared-validation`: Zod schemas for NestJS DTOs and React Hook Form (built to `dist`, mirrored).
- `shared-config`: runtime constants such as MIME lists and size thresholds (built to `dist`, monorepo only).
- `ui-primitives`: headless ShadCN and Radix components with the Tailwind v4 theme tokens (source only).
- `api-client`: typed React Query hooks generated by orval from the API's OpenAPI document (source only).

A `dist` package needs `npm run build` before its consumers see an edit; Turborepo's `build → ^build` order does it.

### Where New Code Goes

When you add a symbol, take the first rule that matches:

1. A runtime constant or threshold both apps must agree on → `packages/shared-config`.
2. A Zod schema validated identically on both sides → `packages/shared-validation` (a factory; the web app overrides messages with i18n).
3. A type, interface or enum used on both sides → `packages/shared-types`, mirrored into both apps when hand-written.
4. A headless UI building block or theme token → `packages/ui-primitives`. App compositions (logos, page loaders, business widgets) stay in `apps/web/src/components/`.
5. A backend endpoint → the controller in `apps/api`, then `npm run codegen`, then the typed hook from `@{{PROJECT_NAME}}/api-client/generated/api/<tag>/<tag>` in `apps/web`.
6. Anything else → `apps/<app>/src/`.

### Module Deposits and Vendored Mirrors

- An installed module may deposit a canonical file into `packages/shared-*`: storage into `shared-config/src/storage.ts` (consumed by `apps/api/.../organization.controller.ts`), email into `shared-types/src/email.ts` (consumed by `apps/api/.../mailersend.service.ts`). Deposits are idempotent. If you delete one, remove its consumer's import in the same change, or the build breaks.
- `shared-types` and `shared-validation` exist twice: the workspace package, and each app's vendored mirror under `src/shared-{types,validation}/`, aliased `@shared-types/*` and `@shared-validation/*`. Change a hand-written file in all three copies, or the other side keeps the old shape.

## 🚀 Commands
