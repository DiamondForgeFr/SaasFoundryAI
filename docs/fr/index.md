## Deux piliers, un seul produit

SaaSFoundryAI ne se limite ni à un boilerplate ni à une couche IA. Le projet combine une architecture SaaS préconçue avec un système de livraison qui explique à chaque agent — humain ou IA — comment
analyser, construire, tester et faire relire une évolution.

### La fondation SaaS

Un projet généré part avec les décisions transverses déjà reliées entre elles : authentification, comptes, entités, organisations, permissions, invitations, réactivation, administration, validation,
API typée, tests et infrastructure locale.

### Le harness de livraison

Le fichier `.saasfoundry.json`, les instructions du projet et les skills `sf-*` relient le code à votre board, vos spécifications et vos règles de validation. Le niveau de rigueur s'adapte à la
complexité du ticket sans supprimer les validations humaines.
