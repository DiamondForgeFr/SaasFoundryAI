# Installation

Install SaaSFoundry globally using your preferred package manager:

::: code-group

```bash [npm]
npm install -g saasfoundry
```

```bash [yarn]
yarn global add saasfoundry
```

```bash [pnpm]
pnpm add -g saasfoundry
```

:::

## Requirements

- Node.js >= 20.19.0
- npm, yarn, or pnpm
- Git

## Verify Installation

```bash
sf --version
```

You should see the version number printed.
