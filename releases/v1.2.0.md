## What this version brings

Generated applications enforce access more strictly: a deactivated user loses API access straight away, and a role only grants rights in the account or entity it is scoped to. The workflow also adds
two checks: a ticket cannot reach Human testing until the local CI checks the project requires pass, and it cannot reach AI testing until its commits are pushed.

### Access control in generated apps

- Tokens of a deactivated user are refused and that user's open sessions are ended.
- A role scoped to an entity no longer passes admin checks on account-level routes, and entity creation and invitations are checked against the target account or entity.
- Only the platform can change system roles; an entity admin can no longer rewrite them for every account.
- The generated stack runs on current versions (React 19.3, Playwright 1.64, Vite 8.3.5), with the known dependency advisories patched.

### Workflow and delegated agents

- `sf workflow set-local-ci` records which local CI checks must pass before Human testing.
- When a guard blocks a step, its message tells the agent to ask the developer, and a delegated agent can no longer use an escape hatch itself.
- A pull request can resolve several tickets, and a pull request marked as "Part of" an issue stays green without moving that issue.
- Delegated agents run only the affected tests while they work and run the full suites once, at AI testing.
- `ready-pr` and `draft-pr` now also work from the main checkout.

### Status and skills

- `sf status` reports delegation outcomes that could not be recorded, personal skills that shadow the project's skills, and AGENTS.md files that still name a deleted CLAUDE.md.
- `sf skill install` installs into the project by default in a managed project.
- The session-start hook runs the project's own CLI and warns when that CLI is out of date.

Several setup problems no longer occur: `services:up` on a new project, workflow labels missing after `sf new --profile full`, `sf update` replacing the email sender, lint hanging after E2E runs,
Codex's instruction size limit, and missing UI classes in worktrees.
